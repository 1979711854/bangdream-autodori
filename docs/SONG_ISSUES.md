## 0. 使用说明

### 0.1 收录口径

**收**：

- 当前版本仍能复现的崩局 / 恒定 miss / 成批 FAST·SLOW；
- 已定位但修法还没落地的；
- 代码或谱面覆盖已改、缺实机复核的（标【已修·待复核】）；
- 只出现过一两次、证据不足但可疑的（标【观察】，留编号防丢）。

**不收**：

- 已实机归零的曲目 —— 移入第 6 节「已关闭存档」，并写明归零依据（哪一局、什么读数）；
- 单局偶发 1~2 miss 且无法复现的 —— 只在第 5 节表格里留一行，不单独立条。

### 0.2 状态标签

| 标签 | 含义 |
|---|---|
| 【未定位】 | 现象稳定存在，成因未定位 |
| 【已定位·未修】 | 成因明确，修法尚未实现 |
| 【已修·待复核】 | 代码或谱面覆盖已改，缺一次实机验证 |
| 【已改·未复核】 | 改动已落，但改完之后一局都没打过 |
| 【已改·未归零】 | 改动已落、实机也打过，问题仍在 |
| 【已结案】 | 已实机归零；正文保留判据与取证，索引在第 6 节 |
| 【观察】 | 证据不足 / 只出现一次，先挂着不投入 |

### 0.3 每条必填字段

`曲目` `状态` `问题类型` `表现` `复现率` `可能成因` `证据路径` `下一步`

「可能成因」必须标可信度：**高** = 有对照实验或逐帧证据；**中** = 机制自洽但未验证；**低** = 只有相关性。

## 7. 复现与取证速查

### 7.1 复现单曲

```powershell
cd e:/autodori-src
$env:PYTHONIOENCODING="utf-8"          # 不设打中文会 UnicodeEncodeError
.venv\Scripts\python.exe src\autodori.py --mode daily --difficulty special   # 日常清火（随机选歌）
.venv\Scripts\python.exe src\autodori.py --mode main  --difficulty expert    # 挑战赛
.venv\Scripts\python.exe src\autodori.py --mode special --special-song "<曲名>"  # 指定特殊曲
```

要打指定曲目：GUI 里选歌，或改 `data/gui_config.json` 的 `special_song` / `song_strategy`。

### 7.2 崩局三步判读

1. `崩局诊断:` 行的**画面分数**：近 0 → 时间线整体错（锚点问题）；已涨过一大截再断 → 曲中段崩；
2. 对照 `首音触发[...]` 的 `band` 与 `顶部7行` 时差：正常 −8~+12ms，>150ms 一律当异常（#413 是 1126ms）；
3. `滞后反馈汇总` / `服务端执行滞后`：曲内增长 ≥20ms 会打 WARNING，lag@ 曲线在 `debug/lagdump/`。

### 7.3 战绩库查询

```powershell
$env:PYTHONIOENCODING="utf-8"
python -c "import sqlite3,json,datetime;c=sqlite3.connect('data/play_records.db');
[print(datetime.datetime.fromtimestamp(t).strftime('%m-%d %H:%M'),cid,d,ok,json.loads(r) if r else '') for t,cid,d,ok,r in c.execute('select play_time,chart_id,difficulty,succeed,result from playrecord where chart_id=? order by play_time',('413',))]"
```

字段：`succeed=0` 且 `result={}` = 崩局（没有结算）；`succeed=1` 才有 miss/fast/slow。

### 7.4 日志关键字

| 关键字 | 用途 |
|---|---|
| `首音触发[` | 锚点时刻、band/顶部判据时差、触发帧 y |
| `冻结完成:` | 冻结耗时，与首音间隔太近要警惕（#413 只差 30ms） |
| `首音候选被拒` | 可信度门是否在拦 |
| `发布批次#N 漂移` | 下发是否领先于谱面时间 |
| `判定点独占帧:` | 插 commit 的处数（谱面结构指纹，可核对覆盖是否生效） |
| `Play result:` / `Play result raw:` | 结算读数（`-1` = 识别失败） |
| `生命检测汇总:` | `命中` = 崩局；`亮度预检跳过` 大 = 弹窗没被看到 |
| `滞后反馈汇总:` | 回执积压、被跳过的 wait（欠账）与该不该告警 |
